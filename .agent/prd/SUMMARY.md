# ParkOrbit Executive Summary

Peer-to-peer parking rental marketplace built with Next.js App Router, TypeScript, Tailwind CSS, and `shadcn/ui`, strictly adhering to `DESIGN-mastercard.md` (`#F3F0EE` Canvas Cream, `#141413` Ink Black, `40px` stadium hero, circular portraits with `56px` satellite CTAs, `#F37338` orbital arcs, `Sofia Sans` 450/500/700 weights). Includes server-side availability conflict detection, configurable commission engine, simulated UPI/Card payments, honest pending/estimated host payouts, driver/host dashboards, and admin moderation.
